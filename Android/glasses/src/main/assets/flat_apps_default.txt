# Apps that always open "flat" on the glasses' own display (native handoff) instead of in the
# head-tracked workspace, because they play Widevine-protected video that a non-secure
# virtual display blanks (audio, no picture).
#
# Format, one app per line:   package|Label|mode
#   mode is optional: "flat" (glasses display + phone trackpad) or "mirror" (phone screen
#   mirrored). Omit it to use the default mode chosen in Diagnostics.
# This file is only the shipped starting point. Additions, removals and mode changes made in
# the launcher or Diagnostics are stored separately and win over it.
#
# Package names were checked against Google Play listings / APK mirrors (Nov 2026) or, where
# marked "corroborated", against open-source projects that hard-code the same id. Apps that are
# not installed are simply never matched.
